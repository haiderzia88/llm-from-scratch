# Chapter 01 — Python and NumPy

**Status: In progress**

Run the Python scripts in this order:

1. `01_python_basics.py` — variables, lists, negative indexing, loops and functions.
2. `02_numpy_arrays.py` — vectors, matrices, array shapes, dot products and broadcasting.
3. `03_matrix_multiplication.py` — 2×2, 5×2 @ 2×2, dimensions, and an example linear layer.
4. `exercises.py` — complete your own practice questions.

Before checking off this chapter, make sure you can explain why `(5, 2) @ (2, 2)` works but `(2, 2) @ (5, 2)` does not.
